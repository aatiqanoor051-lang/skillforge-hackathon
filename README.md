# SkillForge Hackathon 2026

A full-stack web application developed for the SkillForge Hackathon.

## Tech Stack
- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **AI/Python Service:** Python

## Features
- User authentication and role management
- Real-time skill assessment and analytics
- Custom dashboard integration
