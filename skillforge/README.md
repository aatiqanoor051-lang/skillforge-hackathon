# SkillForge

SkillForge is an AI-powered career-readiness platform for technology students.
Students describe their current skills and target role, take a short
role-specific assessment, receive a deterministic skill-gap analysis, and get
a personalized 4-week learning roadmap — generated by an LLM when configured,
with a fully deterministic rule-based fallback when it isn't. Mentors can
track assigned students; admins manage the user base, quiz bank, and role
benchmark catalog.

## Architecture

```
                 ┌─────────────────┐
                 │   React (Vite)  │   Frontend — SPA served by Nginx in prod
                 └────────┬────────┘
                          │ REST (JSON), JWT bearer auth
                 ┌────────▼────────┐
                 │  Node/Express   │   API gateway — auth, RBAC, business
                 │   API Gateway   │   logic, AI orchestration, Mongo access
                 └───┬────────┬────┘
                     │        │
        ┌────────────▼──┐   ┌▼─────────────────┐
        │   MongoDB      │   │ FastAPI (Python) │  Deterministic skill-gap
        │ (Mongoose ODM) │   │ Analysis Service  │  scoring engine
        └────────────────┘   └───────────────────┘
                     │
        ┌────────────▼──────────────┐
        │  AI Service (in backend)  │  Roadmap generator + RAG-grounded
        │  OpenAI-compatible client │  AI Coach, local Markdown knowledge base
        └────────────────────────────┘
```

- **Frontend** (`/frontend`): React + Vite + Tailwind SPA. Role-aware
  navigation (student / mentor / admin), assessment flow, roadmap viewer,
  resource library, admin console, and a floating AI Coach widget.
- **Backend** (`/backend`): Express API gateway. Owns authentication (JWT +
  bcrypt), RBAC middleware, MongoDB persistence (Mongoose models), the AI
  roadmap generator (with structured-output validation, one retry, and a
  deterministic fallback), a small RAG engine over a local Markdown knowledge
  base, and an agentic AI Coach with two authorization-checked tools.
- **Python analysis microservice** (`/python-service`): FastAPI service
  exposing `POST /api/analyze`. Wraps a strictly object-oriented
  `SkillAnalyzer` class that performs deterministic quiz scoring and
  skill-gap/proficiency-gap analysis via set operations — fully unit tested,
  independent of the HTTP layer.
- **MongoDB**: Users, Profiles, QuizQuestions, Assessments, Roadmaps,
  Resources, RoleRequirements.

## Quickstart (Docker Compose)

```bash
cp .env.example .env
# Edit .env: set a strong JWT_SECRET at minimum. AI_API_KEY is optional —
# leave it blank to run entirely in deterministic/offline mode.

docker-compose up --build

# In a separate terminal, once mongo/backend are healthy:
docker-compose exec backend npm run seed
```

Then open:
- Frontend: http://localhost:5173
- Backend health: http://localhost:5000/health
- Python service health: http://localhost:5001/health

If `ENABLE_DEMO_ACCOUNTS=true` (the default), the seed script creates three
demo accounts, all with password `DemoPass123!`:
- `demo.student@skillforge.local`
- `demo.mentor@skillforge.local`
- `demo.admin@skillforge.local`

## Quickstart (without Docker)

Requires Node.js 18+, Python 3.11+, and a running MongoDB instance.

```bash
./scripts/setup.sh          # copies .env, installs all dependencies
# Start MongoDB locally (or point MONGO_URI in .env at a hosted instance)

# Terminal 1
cd python-service && uvicorn app:app --reload --port 5001

# Terminal 2
cd backend && npm run seed && npm run dev

# Terminal 3
cd frontend && npm run dev
```

## Running tests

```bash
./scripts/test.sh
# or individually:
cd backend && npm test
cd python-service && python -m pytest test_analyzer.py -v
```

Backend tests use `mongodb-memory-server`, so they don't require a running
MongoDB instance or network access. See `backend/tests/` and
`python-service/test_analyzer.py`.

## Key design decisions

- **AI is optional, never required.** If `AI_API_KEY` is unset, the roadmap
  generator and AI Coach both run in fully deterministic modes — the app is
  functional end-to-end without any external AI provider.
- **Structured-output validation with retry.** The LLM roadmap generator
  validates the model's JSON against a strict schema; on failure it retries
  once with a correction prompt, then falls back to a deterministic roadmap
  built directly from the student's missing skills.
- **RBAC is enforced server-side.** `backend/middleware/roleMiddleware.js`
  and `authMiddleware.js` are the actual authorization boundary. The
  frontend's `ProtectedRoute` is UX only.
- **Prompt-injection awareness.** Retrieved knowledge-base passages, tool
  results, and user profile data are always wrapped and labeled as untrusted
  reference data in prompts — see `backend/ai-service/agent.js` and
  `generator.js`.
- **Agent tool authorization.** The two agent tools (`getUserSkills`,
  `getSkillGaps`) validate arguments and enforce that a student can only ever
  access their own data; mentors/admins may access any student's data.
